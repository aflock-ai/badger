# Connector tool reference

This page lists the MCP tools each connector on this branch registers, as the connector itself
reports them over `tools/list` with writes enabled. It is generated by `docs/tools/generate.ts`,
which builds and runs every connector under `testifysec/connectors/`, so it cannot drift from the
code. Each tool is labelled from its MCP `readOnlyHint` annotation: Read when the hint is true,
Write when it is false. The shared connector library registers a Write tool only when the
connector runs with `--enable-writes`.

The Jira, Confluence and GitLab connectors are on `main`; `example` is the reference connector
for authors. A managed Badger session cannot load a connector yet; see
[connectors](../concepts/connectors.md).
