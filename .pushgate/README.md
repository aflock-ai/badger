# Formal verification steps

Only the formal-verification steps are published here: `steps/formal.sh` and the files it uses
(`formal-audit.lean`, `formal-cite.py`, `formal-extract.py`, `formal-order.py`,
`formal-harness/`). `testifysec/formal/contract/check.sh` runs them. See that directory's README.

The rest of TestifySec's development-repository push gate is not part of this repository.
